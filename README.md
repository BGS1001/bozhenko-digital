# Bozhenko Digital — сайт

Статичный сайт без сборки: просто откройте `index.html` в браузере.

## Что где менять
Все настройки в **config.js** (открывается в Блокноте):
- `whatsapp`, `email`, `instagram`, `tiktok`, `facebook` — контакты. Пустое значение = скрыто.
- `formEndpoint` — заявки идут на bozhenkodigital@gmail.com через FormSubmit. Первая заявка пришлёт письмо активации: один раз нажмите ссылку в нём.
- `offerEnds` — дата окончания акции (таймер и бегущая строка). `""` = без таймера.
- `extras` — доп. услуги (в т.ч. видео/фотосъёмка); у каждой кнопка «Request a quote», запрос приходит на почту.
- `packages` — цены пакетов.
- `work` — пример работы. Видео класть в `assets/work/`: `video` — полное видео со звуком, `preview` — лёгкий беззвучный ролик для первого экрана, `poster` — кадр-превью (.webp или .jpg).
- `siteUrl` — адрес сайта (для превью в соцсетях и Google).

## Кнопка «Magic»
Плавающая кнопка справа переключает сайт из ирландского стиля в творческий («киностудия») через эффект дыма и обратно. Стили обоих видов в `styles.css` (`[data-look="irish"]` и `[data-look="creative"]`).

## Публикация
Код лежит на GitHub (BGS1001/bozhenko-digital, ветка main). Vercel публикует сайт автоматически после каждого изменения в main.

## Что ещё есть
- `privacy.html` — политика конфиденциальности и cookies (GDPR, Ирландия). Контакты в ней прописаны текстом: при смене почты или телефона поменяйте и там.
- `404.html` — страница «не найдено». `robots.txt` и `sitemap.xml` — для Google.
- `assets/fonts/` — шрифты лежат на самом сайте (быстрее и без передачи IP посетителей в Google). Лицензия шрифтов: SIL Open Font License.
- `vercel.json` — заголовки безопасности и кеширования. Если добавите сторонний сервис (аналитику, чат), его адрес нужно разрешить в `Content-Security-Policy`.
